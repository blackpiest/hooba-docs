# Что нужно для сервера

Hooba — сервер для одного сообщества: текстовые каналы, голосовые комнаты до 8 человек, демонстрация экрана, роли, реакции и оформление профилей. Вы ставите его на свой арендованный сервер (VPS), и всё — переписка, картинки, пароли — хранится только у вас.

## Сервер (VPS)

| | Минимум | Комфортно |
|---|---|---|
| Система | Ubuntu 22.04+ или Debian 12+ | Ubuntu 24.04 |
| Память | 2 ГБ | 4 ГБ |
| Диск | 10 ГБ | 20 ГБ и больше — картинки чата занимают место |
| Сеть | внешний (публичный) IPv4 | |

::: tip Сервер с 1 ГБ памяти
Работать будет, но сборка может не уместиться в память. Установщик это заметит и предложит включить swap-файл на 2 ГБ — соглашайтесь.
:::

Docker, certbot, git и всё остальное ставить заранее не нужно — скрипт установит сам.

## Адрес: домен или IP

Участники будут открывать сервер по адресу `https://…`. Есть два варианта:

- **По домену**, например `chat.mysite.ru`. Домен покупается отдельно; в панели, где он куплен, нужно создать A-запись на IP сервера. Адрес красивый и запоминается.
- **По IP-адресу**, например `https://203.0.113.10`. Ничего покупать не нужно, сертификат на IP выпускается автоматически. Проще для начала — перейти на домен можно позже (см. [Адрес и сертификат](/server/certificates)).

## Порты

Если у хостинга есть брандмауэр в панели управления (Firewall, Security groups, «Сетевой экран»), откройте в нём входящие порты **до установки** — иначе не выпустится сертификат и не заработает голос.

| Порт | Протокол | Зачем |
|---|---|---|
| 80, 443 | TCP | сайт и выпуск сертификата |
| 3478 | UDP + TCP | голос (TURN/STUN) |
| 5349 | TCP | голос через TLS |
| 40000–40100 | UDP + TCP | голос |
| 50000–50100 | UDP | голос (relay) |

Подробнее — [Порты и брандмауэр](/server/ports).
