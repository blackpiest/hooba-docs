# Подключение к серверу

После покупки VPS хостинг присылает **IP-адрес**, **логин** (обычно `root`) и **пароль**. Все команды из этой документации вводятся в терминале **сервера** — если не сказано иное.

## Откройте терминал на своём компьютере

- **Windows** — Пуск → наберите «PowerShell» → откройте.
- **macOS** — Программы → Утилиты → «Терминал».
- **Linux** — «Терминал» из меню приложений.

## Подключитесь

Вместо `<IP>` — адрес сервера из письма хостинга:

```bash
ssh root@<IP>
```

1. При первом подключении появится вопрос `Are you sure you want to continue connecting?` — введите `yes` и нажмите Enter.
2. Введите пароль из письма. **Символы при вводе не отображаются** — это нормально, просто наберите и нажмите Enter.
3. Когда строка сменится на что-то вроде `root@server:~#`, вы на сервере.

Выйти с сервера — команда `exit` или закрыть окно.

## Если не пускает

| Сообщение | Что делать |
|---|---|
| `Permission denied` | Неверный пароль. Скопируйте его из письма заново; у некоторых хостингов пароль можно сбросить в панели. |
| `Connection timed out` | Неверный IP или сервер ещё создаётся. Подождите пару минут, проверьте IP в панели. |
| `Connection refused` | SSH на сервере слушает нестандартный порт. Посмотрите в панели и подключайтесь так: `ssh -p <порт> root@<IP>`. |

## Вставка текста в терминал

- **PowerShell** — правая кнопка мыши или Ctrl+V.
- **Терминал macOS** — Cmd+V.
- **Linux** — Ctrl+Shift+V.
