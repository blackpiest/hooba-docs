# Первый вход и владелец

## Создайте владельца

1. Откройте в браузере `https://<домен-или-IP>/setup`.
2. Введите **токен настройки**, который показал установщик.
3. Задайте название сообщества (3–50 символов), придумайте логин и пароль владельца (не короче 8 символов). Аватар сервера можно загрузить сразу или позже.

Владелец (роль **OWNER**) — главный аккаунт сообщества: ему доступно всё, включая роли, приглашения для администрации и настройки сервера. Владелец на сервере один.

::: warning Пароль владельца не восстанавливается
Восстановления по почте в Hooba нет. Сохраните пароль в менеджере паролей.
:::

::: tip Потеряли токен настройки?
Установщик сохранил его вместе с паролями в `/opt/hooba/logs/owner-summary.txt`. Посмотреть: `cat /opt/hooba/logs/owner-summary.txt`. После создания владельца страница `/setup` больше не работает.
:::

## Что сделать сразу после

1. **Создайте каналы** — текстовые и голосовые ([как](/community/channels)).
2. **Пригласите людей** — регистрация только по коду приглашения ([как](/community/invites)).
3. **Назначьте администраторов**, если будете модерировать не в одиночку ([кто что может](/community/permissions)).
4. **Проверьте голос**: зайдите в голосовой канал с двух устройств из разных сетей (например, компьютер и телефон на мобильном интернете). Если не слышно — [проверьте порты](/server/ports).
5. **Скачайте файл с паролями** `.env.prod` к себе ([как](/start/install#сохраните-пароли-к-себе)).
