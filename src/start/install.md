# Установка

## Одна команда

Подключитесь к серверу ([как](/start/ssh)) и выполните:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/blackpiest/hooba-app/main/install.sh)
```

Скрипт сам скачает Hooba в папку `/opt/hooba`, установит всё нужное и запустит сервер.

::: tip curl: command not found
Сначала выполните `apt update && apt install -y curl`, затем команду установки ещё раз.
:::

::: info Первый раз ставите сервер?
Проверьте, что VPS подходит и порты открыты, — [Что нужно](/start/requirements). Как попасть в терминал сервера — [Подключение к серверу](/start/ssh).
:::

## Что спросит установщик

1. **Как открывать сервер** — `1` по домену или `2` по IP-адресу.
   - Для домена: введите его без `https://` (например `chat.mysite.ru`). Скрипт проверит, что A-запись домена указывает на этот сервер. Если нет — подскажет, что исправить; DNS обновляется от нескольких минут до пары часов.
   - Для IP: скрипт сам определит внешний адрес и предложит его — обычно достаточно нажать Enter.
2. **Email для Let's Encrypt** — на него придут письма, если с сертификатом что-то не так. Можно оставить пустым.
3. **Сколько места отдать под картинки чата** — по умолчанию 5 ГиБ. Когда место заполнится на 80%, самые старые картинки удаляются сами. Изменить можно в любой момент ([подробнее](/server/storage)).
4. **Брандмауэр UFW** — предложит включить его и открыть только SSH и порты Hooba. Ваш текущий порт SSH скрипт определяет сам и не закроет.
5. **Ночные резервные копии** — каждую ночь в 03:30, хранятся 14 последних. Рекомендуем согласиться.

Если на сервере уже работает свой nginx, Apache или coturn и занимает нужный порт, скрипт предложит его остановить: Hooba запускает собственные в контейнерах.

Первая сборка занимает **5–15 минут**.

## Готово

В конце скрипт покажет адрес сервера и **токен настройки**. Дальше — [первый вход](/start/first-setup).

## Если установка остановилась с ошибкой

Скрипт напишет, на каком шаге остановился и что проверить. Исправьте причину и **запустите ту же команду ещё раз** — уже сделанное не пострадает. Частые причины — в разделе [Если что-то сломалось](/server/troubleshooting).

## Сохраните пароли к себе

В файле `/opt/hooba/infra/docker/.env.prod` лежат пароли сервера. **Без него резервную копию базы на новом сервере не восстановить.** Скачайте его на свой компьютер — эту команду вводите **на компьютере**, в новом окне PowerShell или Терминала, а не на сервере:

```bash
scp root@<IP>:/opt/hooba/infra/docker/.env.prod .
```

Файл появится в папке, где открыт терминал (в Windows обычно `C:\Users\<имя>`). Никому его не показывайте.

## Установка вручную через git

Если не хочется запускать скрипт из интернета одной строкой:

```bash
apt update && apt install -y git
git clone https://github.com/blackpiest/hooba-app.git /opt/hooba
cd /opt/hooba
chmod +x install.sh
./install.sh install
```

После установки на сервере появится команда [`hooba`](/server/hooba-command).
