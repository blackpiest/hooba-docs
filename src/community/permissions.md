# Кто что может

В Hooba три встроенные роли и сколько угодно своих.

## Встроенные роли

| Роль | Кто | Как получить |
|---|---|---|
| **Владелец** (OWNER) | Главный аккаунт, один на сервер | Создаётся при [первом входе](/start/first-setup) |
| **Администратор** (ADMIN) | Помощники-модераторы | Владелец: меню участника → «Сделать админом» |
| **Участник** (MEMBER) | Все остальные. По умолчанию называется «Нормис» — переименовать можно в разделе «Роли» | Есть у каждого |

Владельца и администраторов вместе называют **администрацией**.

## Что может администрация

| Действие | Владелец | Админ |
|---|:---:|:---:|
| Создавать, менять, удалять каналы и менять их порядок | ✓ | ✓ |
| Закреплять сообщения, удалять чужие сообщения | ✓ | ✓ |
| Исключать, блокировать, скрывать имя участника | ✓ | ✓ |
| Заглушать, перемещать, выгонять из голосового канала | ✓ | ✓ |
| Смотреть жалобы и журнал | ✓ | ✓ |
| Рассматривать жалобы на администрацию | ✓ | |
| Модерировать других администраторов | ✓ | |
| Назначать и снимать админов | ✓ | |
| Создавать и выдавать свои роли | ✓ | |
| Коды приглашений для администрации, рубильник личных приглашений | ✓ | |
| Аватар сервера, свои реакции, фильтр слов | ✓ | |
| Объявления, испытания, значки и титулы | ✓ | |

## Права в каналах

Администрация не подчиняется запретам ролей — может писать, говорить и транслировать везде. Исключение — **приватные каналы**: их видят только те, кого отметили в настройках канала.

Обычным участникам права ограничиваются двумя способами:

- **Правами роли** — действуют во всех каналах ([Роли](/community/roles)).
- **Правилами канала** — «кто может писать», «кто может говорить» и т. д. в настройках конкретного канала ([Каналы](/community/channels)).

Если хоть одна роль участника что-то запрещает — запрет побеждает, даже если другие его роли это разрешают.
