# Объявления

Объявление — окно, которое всплывает у участников поверх приложения в назначенное время. Подходит для важного: правила, событие, техработы. Создаёт объявления только владелец.

## Создать

Панель управления → **«Объявления»** → новое объявление:

1. Напишите текст.
2. Выберите время показа — по часам сообщества.
3. Выберите, кому показать: **всем**, участникам с определёнными **ролями** или конкретным **участникам**.

## Как доставляется

- В назначенное время объявление получают все, кто подходит под выбранную аудиторию на этот момент. Кто был в сети — увидит сразу, остальные — при следующем входе.
- Каждый видит объявление один раз.
- Кто пришёл на сервер после времени показа, объявление не получит.

Запланированное объявление можно изменить или удалить. Удаление записывается в журнал.
