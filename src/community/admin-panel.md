# Панель управления

Панель открывается кнопкой со **щитом** в шапке списка каналов, рядом с названием сервера. Кнопку видят только владелец и администраторы. Красный счётчик на ней — число новых [жалоб](/community/reports).

## Разделы

| Раздел | Что там | Кому доступен |
|---|---|---|
| Сервер | Аватар сервера | владелец |
| Инвайты | Рубильник личных приглашений, коды администрации | владелец |
| Жалобы | Жалобы участников друг на друга | владелец, админы |
| Роли | Свои роли, их права, цвет, значок, участники с ролью | владелец |
| Испытания | Условия, за выполнение которых участники получают награды | владелец |
| Объявления | Окно-объявление для участников в назначенное время | владелец |
| Витрина | Тексты значков и титулов, что видно в конструкторе профиля | владелец |
| Реакции | Свои картинки-реакции | владелец |
| Фильтр слов | Слова, которые заменяются звёздочками | владелец |
| Журнал | Кто кого заблокировал, исключил, какие каналы удалены и т. д. | владелец, админы |

## Что делается не в панели

Многие действия — прямо там, где они нужны:

| Действие | Где |
|---|---|
| Создать канал | Кнопка «+» у заголовка «Текстовые каналы» или «Голосовые каналы» |
| Изменить или удалить канал | Правый клик по каналу → «Редактировать» / «Удалить канал» |
| Порядок каналов | Перетащить канал мышью |
| Действия с участником | Правый клик по участнику в списке участников или кнопка «…» |
| Действия в голосовой комнате | Правый клик по участнику в голосовом канале |
| Закрепить или удалить сообщение | Меню сообщения → «Закрепить» / «Удалить» |
