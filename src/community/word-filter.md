# Фильтр слов

Слова из списка в сообщениях автоматически заменяются звёздочками той же длины: `*****`. С таким словом нельзя зарегистрироваться (в логине) и сохранить отображаемое имя.

## Настроить

Панель управления → **«Фильтр слов»** → введите слово → «Добавить слово». Каждое добавление и удаление сохраняется сразу. Всего — до 500 слов.

Пустой список — сообщения не фильтруются.

## Шаблоны

Звёздочка ставится только по краям слова:

| Шаблон | Что ловит | Пример |
|---|---|---|
| `слово` | только это слово целиком | `дурак` — «дурак», но не «дурака» |
| `слово*` | слова, которые **начинаются** с этого | `дурак*` — «дурак», «дурака», «дураки» |
| `*слово` | слова, которые **заканчиваются** этим | |
| `*слово*` | слова, которые **содержат** это | |

Регистр не важен, `ё` и `е` считаются одной буквой. Заменяется всё слово, в котором нашлось совпадение, а знаки препинания вокруг остаются.

## Что важно знать

- Фильтр действует на **новые и отредактированные** сообщения. Уже отправленные остаются как были — их можно удалить через меню сообщения.
- Исключений нет: фильтр действует и на администрацию.
- Уже существующие логины и имена не перепроверяются — если нужно, [скройте имя](/community/moderation#меню-участника).
