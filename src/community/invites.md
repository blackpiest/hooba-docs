# Приглашения

Зарегистрироваться на сервере Hooba можно **только по коду приглашения**. Случайный человек, нашедший адрес сервера, не войдёт.

## Личные приглашения

У каждого участника есть **3 одноразовых кода**. Их видно по кнопке с человечком и плюсом в шапке списка каналов («Пригласить друзей»). Каждый код можно отправить ссылкой или скопировать.

- Код одноразовый: после регистрации по нему он больше не работает.
- Сервер запоминает, кто кого пригласил.
- Если участника исключили или заблокировали, его неиспользованные коды перестают работать.

### Выключить личные приглашения

Хотите, чтобы новых людей приглашала только администрация, — в панели управления, раздел **«Инвайты»**, выключите переключатель «Приглашения участников». Коды участников перестанут работать, а кнопка приглашений пропадёт. При включении коды вернутся.

## Коды администрации

Одноразовые коды, которые не зависят от рубильника личных приглашений. Создаёт их только владелец:

1. Панель управления → **«Инвайты»** → «Коды администрации» → **«Новый код»**.
2. Отправьте код или ссылку человеку.

В списке видно, кто создал код. Ненужный код удаляется кнопкой с корзиной.

## Кто по какому коду пришёл

Регистрации записываются в раздел **«Журнал»** панели управления.

## Вернуть исключённого участника

Исключённый участник может вернуться с **новым** кодом приглашения — аккаунт и его история сохраняются. Заблокированный — нет, см. [Модерация](/community/moderation#разблокировать).
