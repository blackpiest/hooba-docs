# Модерация

Модерировать могут владелец и администраторы. Действия над **администраторами** доступны только владельцу. Владельца модерировать нельзя.

Все действия ниже записываются в **«Журнал»** панели управления: кто, кого, когда и с какой причиной.

## Меню участника

Правый клик по участнику в списке участников справа или кнопка **«…»** рядом с ним. Каждый пункт открывает окно подтверждения, где можно указать причину.

| Пункт | Что происходит | Обратимо |
|---|---|---|
| Скрыть имя | Отображаемое имя стирается, вместо него виден логин. Новое имя участник задать не сможет | «Разрешить имя» — участник снова может задать имя (старое не вернётся) |
| Исключить | Участника выкидывает с сервера, снимаются все его роли. Аккаунт и сообщения остаются | Вернуться можно с новым [кодом приглашения](/community/invites) |
| Заблокировать | Аккаунт закрыт: войти больше нельзя. Сообщения остаются | См. [Разблокировать](#разблокировать) |

Для владельца в этом же меню: «Сделать админом» / «Снять админа», «Роли…», «Значки и титулы…».

## В голосовом канале

Правый клик по участнику в голосовом канале:

| Пункт | Что происходит |
|---|---|
| Заглушить микрофон | Участник остаётся в канале, но не может говорить, пока с него не снимут заглушение |
| Переместить | Перенести участника в другой голосовой канал |
| Выгнать | Отключить участника от голосового канала. На сервере он остаётся |

Громкость отдельного участника в этом же меню — личная настройка, другие её не слышат.

## Сообщения

- **Удалить чужое сообщение** — меню сообщения → «Удалить».
- **Фильтр слов** — заменяет запрещённые слова звёздочками автоматически ([подробнее](/community/word-filter)).

## Разблокировать

::: warning Кнопки разблокировки пока нет
В текущей версии блокировку нельзя снять из интерфейса. Если нужно, это делается командой на сервере.
:::

Подключитесь к серверу и выполните, подставив **логин** участника вместо `ник`:

```bash
cd /opt/hooba && docker compose --env-file infra/docker/.env.prod -f infra/docker/docker-compose.prod.yml \
  exec postgres psql -U postgres north_star \
  -c "UPDATE \"User\" SET \"isActive\" = true WHERE username = 'ник';"
```

Ответ `UPDATE 1` — готово, участник может войти. `UPDATE 0` — логин написан неверно.

Роли участника сохраняются, а личные правила каналов (например, доступ к приватному каналу как «человеку») при блокировке были сняты — их нужно выдать заново.
