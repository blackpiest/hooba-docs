# Резервные копии

## Что сохраняется

| Файл в `/opt/hooba/backups/` | Что внутри |
|---|---|
| `north_star-<дата>.sql.gz` | База: участники, сообщения, каналы, роли, настройки сообщества |
| `uploads-<дата>.tar.gz` | Картинки чата, аватар сервера, свои реакции |
| `env-<дата>.copy` | Копия файла с паролями `.env.prod` |

## Ночные копии

При установке скрипт предлагает включить их — каждую ночь в **03:30** сохраняется копия **базы** (без картинок), хранятся **14 последних**. Копии, сделанные вручную, не удаляются никогда.

Проверить, включены ли ночные копии и когда была последняя, — `hooba status`. Включить, если отказались при установке, — `hooba install` (спросит снова). Отключить:

```bash
rm /etc/cron.d/hooba-backup
```

## Сделать копию вручную

```bash
hooba backup               # база, настройки и картинки
hooba backup --no-uploads  # без картинок — быстрее и меньше
```

## Храните копии не только на сервере

Копии лежат на том же сервере. Если сервер сломается или хостинг его удалит — пропадут и они. Время от времени скачивайте папку к себе. Команду вводите **на своём компьютере**:

```bash
scp -r root@<IP>:/opt/hooba/backups .
```

## Восстановить

```bash
hooba restore
```

Без аргументов берётся **самая свежая** копия базы. Если рядом есть архив картинок с той же датой, скрипт предложит восстановить и его. Можно указать файлы явно:

```bash
hooba restore /opt/hooba/backups/north_star-20261101-033000.sql.gz /opt/hooba/backups/uploads-20261101-033000.tar.gz
```

::: warning Текущие данные будут заменены
Всё, что произошло после момента копии, пропадёт. Перед восстановлением скрипт сохранит текущую базу в `backups/…-before-restore.sql.gz` — если выбрали не ту копию, можно вернуться.
:::

Посмотреть список копий:

```bash
ls -lh /opt/hooba/backups
```
