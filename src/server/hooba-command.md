# Команда hooba

Всем сервером управляет одна команда — `hooba`. Её можно вводить на сервере из любой папки.

## Меню

Проще всего набрать просто:

```bash
hooba
```

Откроется меню — действие выбирается номером:

```text
======================================================================
  Hooba — управление сервером https://chat.mysite.ru
======================================================================

  Работа сервера
    1) Статус: всё ли в порядке
    2) Запустить сервер
    3) Остановить сервер
    4) Починить: перезапустить всё заново (данные не трогаются)

  Обновление
    5) Обновить Hooba до новой версии
    6) Откатить последнее обновление

  Журналы и проверка
    7) Журнал сервера (выход — Ctrl+C)
    8) Проверить, что сервер отвечает
    9) Проверить голос: почему участники не слышат друг друга

  Резервные копии
   10) Сделать резервную копию
   11) Восстановить из копии

  Настройки
   12) Место под картинки чата
   13) Сменить адрес сервера или переустановить
   14) Заново настроить продление сертификата

    0) Выход
```

## Все команды

| Команда | Что делает |
|---|---|
| `hooba status` | Всё ли в порядке: контейнеры, ответ сервера, срок сертификата, место на диске, последняя копия |
| `hooba start` | Запустить сервер |
| `hooba stop` | Остановить сервер |
| `hooba repair` | Пересоздать все контейнеры. Данные (база, картинки, настройки) не трогаются |
| `hooba update` | Скачать новую версию и перезапустить. Копия базы делается сама — [подробнее](/server/update) |
| `hooba rollback` | Вернуть версию до последнего обновления |
| `hooba logs [сервис]` | Журнал: `backend` — сервер, `web` — сайт, `postgres` — база, `coturn` — голос. Выход — Ctrl+C |
| `hooba validate` | Проверить, что сервер отвечает |
| `hooba voice-check` | Найти, почему не работает голос: контейнеры, адреса, доходят ли пакеты до сервера. Собирает отчёт без паролей в `/opt/hooba/logs/voice-check-report.txt` |
| `hooba backup` | Резервная копия базы, настроек и картинок — [подробнее](/server/backups) |
| `hooba restore [файл]` | Восстановить из копии |
| `hooba uploads-quota [ГиБ]` | Место под картинки чата — [подробнее](/server/storage) |
| `hooba install` | Повторно — сменить адрес сервера или квоту; пароли и данные сохраняются |
| `hooba cert-hooks` | Заново настроить автопродление сертификата |
| `hooba help` | Список команд |

## Журналы команд

Каждая команда пишет полный журнал в `/opt/hooba/logs/<команда>.log`. Если что-то пошло не так, скрипт сам покажет, на каком шаге и что проверить, — исправьте причину и запустите команду ещё раз: повторный запуск безопасен.

## Если `hooba` не находится

При ошибке `hooba: command not found` то же самое работает так:

```bash
/opt/hooba/install.sh status
```

Первый же такой запуск под `root` снова включит команду `hooba`.

## Где что лежит

| Путь | Что там |
|---|---|
| `/opt/hooba` | Hooba целиком |
| `/opt/hooba/infra/docker/.env.prod` | Пароли и настройки сервера. **Не публикуйте и не удаляйте** |
| `/opt/hooba/logs/` | Журналы команд, `owner-summary.txt` — сводка установки с токеном настройки |
| `/opt/hooba/backups/` | Резервные копии |
| `/etc/letsencrypt/live/<адрес>/` | Сертификат |
