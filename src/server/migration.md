# Переезд на другой сервер

Сменить хостинг или тариф можно без потери данных: участники, сообщения и картинки переедут вместе с паролями сервера.

## 1. На старом сервере — сделайте копию

```bash
hooba backup
```

## 2. На своём компьютере — скачайте её

```bash
scp -r root@<СТАРЫЙ-IP>:/opt/hooba/backups .
```

В папке `backups` окажутся копия базы, архив картинок и файл `env-<дата>.copy` — это ваш `.env.prod`.

## 3. Направьте адрес на новый сервер

- **Домен**: в панели, где куплен домен, поменяйте A-запись на IP нового сервера. Подождите, пока изменение разойдётся (от нескольких минут до пары часов).
- **IP**: адрес сменится вместе с сервером. Участникам приложения для компьютера придётся ввести новый адрес.

## 4. На новом сервере — подготовьте Hooba с прежними паролями

[Подключитесь](/start/ssh) к новому серверу и скачайте Hooba, **не запуская установку**:

```bash
apt update && apt install -y git
git clone https://github.com/blackpiest/hooba-app.git /opt/hooba
mkdir -p /opt/hooba/backups
```

С компьютера загрузите копии на новый сервер:

```bash
scp backups/* root@<НОВЫЙ-IP>:/opt/hooba/backups/
```

Снова на новом сервере — положите файл с паролями на место (дату подставьте свою):

```bash
cp /opt/hooba/backups/env-<дата>.copy /opt/hooba/infra/docker/.env.prod
chmod 600 /opt/hooba/infra/docker/.env.prod
```

## 5. Установите и восстановите

```bash
cd /opt/hooba && ./install.sh install
```

Скрипт скажет, что Hooba уже установлен, и спросит, переустановить ли, — ответьте `y`. Пароли он возьмёт из файла, а адрес и сертификат спросит заново.

Когда установка закончится:

```bash
hooba restore
```

Согласитесь восстановить и картинки. Готово — откройте сайт и проверьте, что всё на месте.

## 6. Старый сервер

Убедитесь, что всё работает, и только потом удаляйте старый сервер.
