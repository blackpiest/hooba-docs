# Обновление и откат

## Обновиться

```bash
hooba update
```

Что происходит:

1. Делается копия базы `backups/north_star-<дата>-before-update.sql.gz`.
2. Скачивается новая версия.
3. Сервер пересобирается (5–15 минут) и перезапускается. Сайт и голос в это время недоступны около минуты.
4. Скрипт проверяет, что новая версия отвечает.

Если новой версии нет, скрипт просто пересоберёт текущую — это безопасно.

::: tip Когда обновляться
Лучше в тихое время — пересборка нагружает сервер, а участников в голосе на время перезапуска отключит.
:::

## Если новая версия не заработала

```bash
hooba rollback
```

Возвращает версию, которая была до последнего `hooba update`, **вместе с базой на момент обновления**.

::: warning Что потеряется при откате
Всё, что произошло после обновления, — новые сообщения, регистрации, изменения настроек. Перед откатом скрипт всё же сохранит текущую базу в `backups/…-before-rollback.sql.gz`, так что ничего не пропадёт безвозвратно.
:::

Когда выйдет исправление, обновитесь как обычно: `hooba update`.

## «Не удалось загрузить обновление»

Обычно это значит, что файлы в `/opt/hooba` правили вручную. Скрипт перечислит такие файлы. Верните их как было и запустите обновление снова:

```bash
git -C /opt/hooba checkout -- .
hooba update
```

Файл `.env.prod`, резервные копии и журналы при этом не трогаются — они не входят в код.

## Приложение для компьютера

Desktop-приложение Hooba обновляется само, отдельно от сервера.
