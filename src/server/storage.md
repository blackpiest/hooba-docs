# Место под картинки

Участники прикрепляют к сообщениям картинки (PNG, JPEG, WebP, до 4 за раз). Они хранятся на диске сервера.

## Как работает квота

- Квоту — сколько места отдать под картинки — вы задаёте при установке, по умолчанию **5 ГиБ**.
- Когда занято **80%** квоты, самые старые картинки удаляются автоматически, пока не останется 70%. В старых сообщениях на их месте будет пометка, что картинка удалена.
- Если на диске осталось меньше 1 ГиБ свободного места, новые картинки не принимаются, даже если квота не заполнена, — чтобы сервер не встал из-за переполненного диска.

## Изменить квоту

```bash
hooba uploads-quota 10     # 10 ГиБ
hooba uploads-quota 0.5    # 512 МиБ
hooba uploads-quota        # спросит и покажет, сколько свободно
```

Минимум — 0.1 ГиБ. Сервер ненадолго перезапустится. Если квоту уменьшить, лишние старые картинки удалятся при ближайшей проверке.

## Сколько места осталось на диске

```bash
hooba status
df -h /
```

Если диск кончается: уменьшите квоту, удалите старые резервные копии из `/opt/hooba/backups` (предварительно скачав нужные к себе) или освободите место от старых образов Docker:

```bash
docker image prune -f
```
