# Control panel

The panel opens with the **shield** button in the header of the channel list, next to the server name. Only the owner and admins can see the button. The red counter on it is the number of new [reports](/en/community/reports).

::: info Interface language
The Hooba app is in Russian. Buttons and tabs are quoted as they appear on screen, with an English translation in brackets.
:::

## Sections

| Section | What's there | Available to |
|---|---|---|
| Сервер (Server) | Server avatar | owner |
| Инвайты (Invites) | Member invites switch, staff codes | owner |
| Жалобы (Reports) | Members' reports about each other | owner, admins |
| Роли (Roles) | Custom roles, their permissions, color, badge, members with the role | owner |
| Испытания (Challenges) | Conditions members meet to earn rewards | owner |
| Объявления (Announcements) | A pop-up announcement for members at a scheduled time | owner |
| Витрина (Showcase) | Badge and title texts, what's visible in the profile editor | owner |
| Реакции (Reactions) | Custom image reactions | owner |
| Фильтр слов (Word filter) | Words replaced with asterisks | owner |
| Журнал (Log) | Who banned or kicked whom, which channels were deleted, and so on | owner, admins |

## What is done outside the panel

Many actions are right where you need them:

| Action | Where |
|---|---|
| Create a channel | The "+" button next to the «Текстовые каналы» (Text channels) or «Голосовые каналы» (Voice channels) heading |
| Edit or delete a channel | Right-click the channel → «Редактировать» (Edit) / «Удалить канал» (Delete channel) |
| Channel order | Drag the channel with the mouse |
| Member actions | Right-click a member in the member list, or the "…" button |
| Voice room actions | Right-click a member in the voice channel |
| Pin or delete a message | Message menu → «Закрепить» (Pin) / «Удалить» (Delete) |
