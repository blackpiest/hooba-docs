# Server avatar and reactions

## Server avatar

The server image appears in the header of the channel list and on the browser tab. You can upload it during the [first login](/en/start/first-setup) or later:

Control panel → **«Сервер»** (Server) → «Аватар сервера» (Server avatar) → choose an image. You can also remove it there.

::: tip
The server name and avatar are visible only to logged-in members — strangers don't see them on the login page.
:::

## Custom reactions

Besides regular emoji, members can put your image reactions on messages: memes, members' faces, the community logo. They can't be used in message text — only as reactions.

Control panel → **«Реакции»** (Reactions) → «Новая реакция» (New reaction):

1. Choose an image — PNG, JPEG or WebP.
2. Set a name: 2–32 characters, lowercase Latin letters, digits and `_`. For example `kek` or `gg_wp`.

You can upload **up to 32** custom reactions. When you reach the limit, delete the ones you don't need. A name can be changed in the «Загруженные» (Uploaded) list.

::: warning Deleting a reaction
A deleted reaction disappears from every message it was put on. It can't be restored.
:::

A single message can have up to 10 different reactions. Who can react in a particular channel is set in the [channel permissions](/en/community/channels#who-can-do-what-in-a-channel).
