# Who can do what

Hooba has three built-in roles and as many custom ones as you like.

## Built-in roles

| Role | Who | How to get it |
|---|---|---|
| **Owner** (OWNER) | The main account, one per server | Created at the [first login](/en/start/first-setup) |
| **Admin** (ADMIN) | Helpers and moderators | By the owner: member menu → «Сделать админом» (Make admin) |
| **Member** (MEMBER) | Everyone else. Named «Нормис» (Normie) by default — you can rename it in the «Роли» (Roles) section | Everyone has it |

The owner and admins together are called **staff**.

## What staff can do

| Action | Owner | Admin |
|---|:---:|:---:|
| Create, edit, delete channels and change their order | ✓ | ✓ |
| Pin messages, delete other people's messages | ✓ | ✓ |
| Kick, ban, hide a member's name | ✓ | ✓ |
| Mute, move, remove from a voice channel | ✓ | ✓ |
| View reports and the log | ✓ | ✓ |
| Handle reports about staff | ✓ | |
| Moderate other admins | ✓ | |
| Appoint and remove admins | ✓ | |
| Create and grant custom roles | ✓ | |
| Staff invite codes, member invites switch | ✓ | |
| Server avatar, custom reactions, word filter | ✓ | |
| Announcements, challenges, badges and titles | ✓ | |

## Channel permissions

Staff aren't subject to role restrictions — they can write, speak and stream everywhere. The exception is **private channels**: only those marked in the channel settings can see them.

Regular members' permissions are limited in two ways:

- **Role permissions** — apply in all channels ([Roles](/en/community/roles)).
- **Channel rules** — "who can write", "who can speak" and so on in a particular channel's settings ([Channels](/en/community/channels)).

If even one of a member's roles forbids something, the restriction wins, even if their other roles allow it.
