# Invites

You can register on a Hooba server **only with an invite code**. A random person who finds the server's address can't get in.

## Member invites

Each member has **3 single-use codes**. They're shown by the button with a person and a plus sign in the header of the channel list («Пригласить друзей», Invite friends). Each code can be sent as a link or copied.

- A code is single-use: once someone registers with it, it stops working.
- The server remembers who invited whom.
- If a member is kicked or banned, their unused codes stop working.

### Turn off member invites

If you want only staff to invite new people, go to the control panel, section **«Инвайты»** (Invites), and turn off the «Приглашения участников» (Member invites) switch. Members' codes stop working and the invite button disappears. When you turn it back on, the codes return.

## Staff codes

Single-use codes that don't depend on the member invites switch. Only the owner can create them:

1. Control panel → **«Инвайты»** (Invites) → «Коды администрации» (Staff codes) → **«Новый код»** (New code).
2. Send the code or link to the person.

The list shows who created each code. Delete a code you don't need with the trash can button.

## Who joined with which code

Registrations are recorded in the **«Журнал»** (Log) section of the control panel.

## Bring back a kicked member

A kicked member can return with a **new** invite code — the account and its history are kept. A banned member can't, see [Moderation](/en/community/moderation#unban).
