# How to join

You can send this page to new members.

## Registration

1. Get an **invite code** or invite link from someone in the community.
2. Open the server address, for example `https://chat.example.com`, or the link from the invite.
3. Click «Регистрация» (Sign up), enter the code and choose a login and password.

::: warning The password can't be recovered
There is no password recovery by email. Keep it in a password manager.
:::

::: info Interface language
The Hooba app is available in Russian only for now.
:::

## In a browser

Hooba works in any modern browser — Chrome, Edge, Firefox, Safari — on a computer and on a phone. The first time you join a voice channel, the browser asks for microphone access — allow it.

On a phone you can add the site to your home screen ("Add to Home Screen" / "Install app" in the browser menu) — it then opens like a separate app.

## Desktop app

The desktop app has things the browser version doesn't: push-to-talk on a global key, a voice channel overlay on top of games, and tray notifications. On first launch, enter the server address, for example `chat.example.com`.

## No sound or voice won't connect

While voice is connecting, grey dots bounce and the frame flickers in the "Голосовая связь" ("Voice connection") panel at the bottom left; once sound is flowing, the ping appears instead. This usually takes 1–3 seconds. On strict networks it can take up to half a minute: Hooba tries a fallback path on its own and shows "Напрямую не получилось — пробуем запасной путь" ("Direct connection failed — trying a fallback path"). Wait a moment, and if that doesn't help:

- Check that the browser has allowed microphone access (the lock or camera icon in the address bar).
- Try another network, such as mobile data. Some office and public networks block voice.
- If it doesn't work for anyone, tell the server owner: the [ports](/en/server/ports) are most likely closed.
