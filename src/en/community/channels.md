# Channels

Channels are either **text** (messages, images, reactions) or **voice** (voice for up to 8 people and screen sharing). Staff can create and change channels.

## Create a channel

1. In the channel list, click **"+"** next to the «Текстовые каналы» (Text channels) or «Голосовые каналы» (Voice channels) heading.
2. Enter a name.
3. If needed, set up privacy and permissions (see below).
4. Click **«Создать»** (Create).

## Edit or delete

Right-click the channel → **«Редактировать»** (Edit) or **«Удалить канал»** (Delete channel).

::: warning Deletion can't be undone
Deleting a text channel deletes all of its messages.
:::

## Channel order

Drag a channel up or down with the mouse. The order is the same for all members.

## Private channel

Turn on **«Приватный канал»** (Private channel) in the channel settings and mark **who can see the channel**:

- **«Роли»** (Roles) — everyone with a marked role sees the channel.
- **«Люди»** (People) — specific members.

Other members don't see the channel at all. Staff see a private channel only if they're marked, like everyone else.

## Who can do what in a channel

In the channel settings you can restrict who:

| Text channel | Voice channel |
|---|---|
| can write | can speak |
| can send images | can stream |
| can add reactions | |

Restrictions are chosen by role; for reactions, also by specific member. For example, a "News" channel where only staff write and everyone else reads and reacts.

These restrictions don't apply to staff.

## Pinned message

Each text channel can have **one** pinned message — it's shown as a bar above the conversation, and clicking the bar scrolls to the message.

Message menu → **«Закрепить»** (Pin). A new pin replaces the old one. To remove it, use **«Открепить»** (Unpin) in the same message's menu. Only staff can pin.

## Delete someone else's message

Message menu → **«Удалить»** (Delete). Deletion is recorded in the log.
